Dataset Description

This dataset contains financial news sentiment information for major U.S. stocks. Each record represents a stock-specific news observation, defined as one news article associated with one stock ticker and its corresponding sentiment information. The dataset includes the stock ticker, publication time, article title, news source, topic, ticker-specific sentiment label, sentiment score, relevance score, and original article URL.

Data Source

The data were collected from the Alpha Vantage NEWS_SENTIMENT REST API using Python and the requests library. The acquisition script sends an HTTP GET request, checks the HTTP status code, parses the JSON response, and extracts the ticker-specific sentiment information from each article. The data were then cleaned and deduplicated before being saved as CSV and JSON files.

The script also uses a User-Agent, request timeout, HTTP error handling, and API-level error checking. The request retrieves up to 1,000 articles in a single API response, so no additional pagination was required for this dataset.

Number of Records

The API returned 1,000 financial news articles. Because one article can contain sentiment information for multiple stock tickers, the article-level data were expanded into individual article-ticker observations. This resulted in 3,300 final records after basic cleaning and deduplication.
