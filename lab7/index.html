Lab 7 — Animated Temporal Commercial Network

How does the structure and connectivity of a commercial network among 12 companies change over 60 days?

How to read the network

Each node is a company and each line is a commercial relationship (treated as undirected). Press Play to animate the 60 days, or drag the slider / click a bar in the overview chart to inspect a specific day. Hover over a node or a link for details. Hovering a node also highlights its current partners.

Because a single day contains only 3–10 transactions, you can switch the time window to a rolling 7 days. In that mode, a link's opacity shows how recently the relationship was active.

Legend and Encodings

Node color — sector

Node shape — region

Link color — transaction type

Size, width and opacity

  • Node size: transaction volume (USD) in the current window.
  • Faded node: no transactions in the current window.
  • Link width: transaction amount (USD) between the two companies.
  • Link color: the type with the largest amount in the window.
  • New link: flashes thicker when it first appears.
  • Disappearing link: fades out.
  • Link opacity (7-day mode): more recent activity is more opaque.

Design Description

Sector is a categorical attribute, so I encode it with node color. Region is encoded with node shape (circle, square, triangle), which makes cross-regional links easy to spot. Node size shows each company's transaction volume in the current window, so it changes over time and shows who is commercially active right now. For links, width encodes the transaction amount and color encodes the transaction type. The exact transaction count is available in the link tooltip.

To preserve the mental map, I use one d3.forceSimulation() with the same node objects for all 60 days. Only the links change, and the simulation restarts gently with alpha(0.3). Each node is also pulled toward a fixed anchor for its region, so companies stay in roughly the same place. The animation can be paused at any time, and the overview bar chart gives a static view of all 60 days, so users can compare distant time points without relying on memory.

Temporal Network Questions

1. How does overall network connectivity change across the 60 days?

Connectivity increases over time. In the first weeks, daily networks are sparse and often split into isolated pairs. After about day 40, more links are active on a typical day, and several days (e.g., days 42, 48, 54, 60) form a large connected group of 8 companies. The overview chart also shows that daily transaction value grows steadily, with clear peaks in the last three weeks.

2. Which companies become more central or commercially active over time?

Fusion Electronics is the main hub in the middle period (about days 21–40), connecting to Granite Wholesale, Harbor Shipping, Juniper Stores, and Lumen Distribution. After day 40, the center shifts to Ion Systems and Cedar Retail. Their nodes grow much larger as they gain many new partners, while Fusion Electronics loses most of its middle-period links.

3. Are there periods when the network consists of relatively separate clusters?

Yes. In the current-day view during the first 20 days, the network is often split into small separate groups. Some days (e.g., days 1, 7, 13, 19) contain only three disconnected pairs, all within the same region. In the rolling 7-day view the network is always connected, but early on it looks like loosely linked regional groups rather than one integrated network.

4. Which commercial relationships appear, disappear, or become stronger over time?

A stable backbone of links recurs throughout all 60 days, such as Apex–BlueRiver, BlueRiver–Cedar, Cedar–Evergreen, and Ion–Lumen. Some early links (BlueRiver–Delta, Cedar–Fusion, Harbor–Keystone) disappear after day 20. Fusion's links with Harbor, Juniper, and Lumen appear around day 21 and end around day 40. After day 40, new links form around Ion Systems (with Apex, Delta, Fusion) and Cedar Retail (with Granite, Harbor, Keystone). Some links also become stronger, such as Ion–Juniper and Fusion–Granite, whose lines become wider in the second half.

5. Does the network become more or less cross-regional over time?

More cross-regional. Most new links after day 40 connect different regions (for example, North American companies such as Cedar Retail and Ion Systems trading with Asian and European companies). The cross-regional share shown in the summary is generally higher in the last 20 days than in the first 20 days, and within-region-only days such as day 1 no longer appear.
