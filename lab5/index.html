Lab 5 — Interactive Network Visualization

1. Dataset Description

This visualization uses the provided synthetic urban transit network containing 50 stations and 50 direct transit connections. The network is treated as undirected, so a connection between two stations represents direct travel between them without implying a direction.

Each station has three attributes: district, daily passengers, and station type. Each direct connection has two attributes: travel time and route type.

2. Node-Link Visualization

Node and Link Encodings

District: Central North South East West
Station type: ○ Terminal □ Transfer ◆ Local
Node size: Larger = more daily passengers
Route type: Metro Express Shuttle
Travel time: Thicker link = longer travel time
Interaction: Drag individual stations to inspect their connections. Hover over a station to highlight its directly connected neighbors and view station information. Hover over a route to highlight the connection and view its route type and travel time. The network can also be panned and zoomed to inspect different parts of the layout.

3. Node-Link Design Description

The node-link view uses color for district, size for daily passenger volume, and shape for station type. These encodings make geographic grouping, station usage, and functional role distinguishable at the same time. Link width represents travel time, while link color represents route type. Dragging and hover highlighting support inspection of local connections, and tooltips provide exact station or route attributes.

4. Adjacency Matrix

5. Matrix Design Description

The matrix uses the same 50 stations as both rows and columns. A filled cell represents a direct connection, with cell color showing route type and opacity showing travel time. Stations are ordered by district, then station type, then ID, which creates visible blocks for comparing district-level connectivity. The matrix preserves individual station connections while making repeated connection patterns easier to compare.

6. Network Questions and Findings

Six questions from the assignment:

  1. Which stations appear central in the network?
  2. Which districts are strongly connected to one another?
  3. Where are transfer or terminal stations located in the topology?
  4. Which stations have high passenger volume?
  5. Where are the longest direct travel-time connections?
  6. Are particular route types concentrated in particular parts of the network?
# Answerability Best Visualization Encoding / Interaction Observation
1 Well Node-link Visible links and hover highlighting show local degree and connectivity. Several degree-3 stations appear relatively central, but there is no single dominant hub.
2 Well Matrix District ordering creates blocks that make cross-district connections easy to compare. East–South, Central–North, and East–West have the strongest connection patterns.
3 Well Node-link Station shape identifies Terminal and Transfer stations within the topology. Terminal and Transfer stations are distributed across the network, with several in relatively well-connected positions.
4 Well Node-link Node size directly encodes daily passenger volume. The largest nodes identify high-volume stations; some are network endpoints, showing that passenger volume and connectivity differ.
5 Well Node-link Link width encodes travel time, making long connections visually prominent. The longest connections include Station 7–Station 31 (16 min) and Station 18–Station 34 (15 min).
6 Partially Both Link color identifies route type; the matrix helps compare repeated route types across district pairs. Route types are distributed across multiple areas rather than concentrated in one region; Express appears frequently on major cross-district connections.
